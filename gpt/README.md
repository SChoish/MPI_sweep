# GPT revision of the MPI AISTATS 2027 manuscript

This directory contains an independently rewritten manuscript grounded in the committed sweep matrices and a code-level audit of the MPI implementation.

## Main changes

- incorporates the complete proximal `K=4` two-seed grid;
- reframes the contribution around fixed-budget stability rather than an isolated routing mechanism;
- calls the implementation a **proximal-loss realization**, not an exact JKO solver;
- treats finite-step descent as conditional on objective improvement;
- documents the `K`-dependent critic-initialization confound;
- separates directly recomputable sweep evidence from inherited diagnostics whose raw logs are absent;
- removes the historical multi-algorithm extension table from the central narrative.

The detailed review is in `CRITICAL_REVIEW.md`.

## Build

```bash
cd gpt
./build_pdf.sh
```

Requirements: Python with NumPy and Matplotlib, plus `latexmk` and a LaTeX distribution. The included AISTATS style is provisional and must be replaced by the official 2027 style when available.

Outputs:

- `paper.pdf`
- `mpi_gpt_aistats27_manuscript.pdf`
- figures under `figures/`
